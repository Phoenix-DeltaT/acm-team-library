# cmath 数学函数

```cpp
#include <cmath>
```

## 绝对值

| 函数 | 说明 |
|------|------|
| `abs(int)` | 整数绝对值 |
| `fabs(double)` | 浮点数绝对值 |
| `llabs(long long)` | 长整型绝对值 |

## 取整

| 函数 | 说明 |
|------|------|
| `floor(double)` | 向下取整 |
| `ceil(double)` | 向上取整 |
| `round(double)` | 四舍五入 |

## 模运算

| 函数 | 说明 |
|------|------|
| `fmod(double x, double y)` | 浮点取模 |

## 指数与对数

| 函数 | 说明 |
|------|------|
| `exp(double)` | e^x |
| `pow(double x, double y)` | x^y |
| `log(double)` | 自然对数 |
| `log10(double)` | 常用对数（底 10） |
| `log2(double)` | 底 2 对数 |

## 三角函数

| 函数 | 说明 |
|------|------|
| `sin(double)` | 正弦 |
| `cos(double)` | 余弦 |
| `tan(double)` | 正切 |

## 开方

| 函数 | 说明 |
|------|------|
| `sqrt(double)` | 平方根 |
| `cbrt(double)` | 立方根 |
