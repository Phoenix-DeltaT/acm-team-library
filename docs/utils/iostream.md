# iostream 输入输出流

```cpp
#include <iostream>
```

## 基础流

使用 `>>` 和 `<<` 进行流的控制

| 流 | 说明 |
|------|------|
| `cout` | 输出数据，无论何种格式 |
| `cin` | 输入数据，并存储为相应格式 |
| `endl` | 提示 cout 作换行处理 |

## 格式控制

| 操纵符 | 说明 |
|------|------|
| `dec` | 提示 cout 以十进制输出整数 |
| `hex` | 提示 cout 以十六进制输出整数 |
| `oct` | 提示 cout 以八进制输出整数 |

> 以上三种在修改格式之前将一直有效

## 整行读取

- `get()`, `getline()` 都可以截取整行的输入
- 唯一的区别是：`getline()` 会丢弃换行符，而 `get()` 不会
- `cin.getline()` 方法读取整行的数据，有两个参数，第一个是数组名称，第二个是录入字符串的长度（包含换行符）
- `getline()` 用于 stream，而 `cin.getline()` 用于 `char*` 类型

## cin.get() 用法

```cpp
// 1. 无参形式：读取单个字符（包括空格、换行符），返回 ASCII 码
char ch = cin.get();

// 2. 单字符参数形式：读取单个字符，返回 cin 对象（便于链式调用）
cin.get(ch1).get(ch2);

// 3. 字符数组参数形式：读取一串字符存入数组，最多读 n-1 个
char str[10];
cin.get(str, 10);  // 最多读 9 个字符，str[9] 存 \0

// 4. 忽略字符形式：丢弃 n 个字符，遇到换行提前停止
cin.get(3);  // 丢弃前 3 个字符
```

> 2、3、4 方法中，返回对象都是 cin 本身

## 其他

```cpp
cin.ignore()  // 省略 cin >> var 后的换行符，进行链式操作
```
