# cctype 字符判断

```cpp
#include <cctype>
```

## 字符判断函数

| 函数 | 说明 | 返回 true 条件 |
|------|------|----------------|
| `isalnum()` | 字母数字 | 参数是字母或数字 |
| `isalpha()` | 字母 | 参数是字母 |
| `iscntrl()` | 控制字符 | 参数是控制字符 |
| `isdigit()` | 数字 | 参数是数字 |
| `isgraph()` | 图形字符 | 参数是除空格外的打印字符 |
| `islower()` | 小写字母 | 参数是小写字母 |
| `isprint()` | 打印字符 | 参数是打印字符 |
| `ispunct()` | 标点符号 | 参数是标点符号 |
| `isspace()` | 空白字符 | 空格、进纸、换行、回车、水平制表、垂直制表 |
| `isupper()` | 大写字母 | 参数是大写字母 |
| `isxdigit()` | 十六进制数字 | 参数是十六进制数字 |

## 大小写转换

| 函数 | 说明 |
|------|------|
| `tolower()` | 如果参数是大写字符，返回其小写，否则返回该参数 |
| `toupper()` | 如果参数是小写字符，返回其大写，否则返回该参数 |
