# 类模板

类模板为 C++ 核心语法，无需额外头文件

- `T` 为类型占位符，可替换为 `int` / `double` / `string` 等任意数据类型

## 语法

```cpp
template<typename T>  // 定义类模板，声明通用数据类型
类名<T>              // 实例化模板类，指定具体存储类型

template<typename T, typename Default=Val>  // 类模板带默认参数
```

模板类成员函数自动适配 T 类型，无需重复编写

## 使用案例

```cpp
template<typename T> class Demo { T data; };

Demo<int> d1;      // 实例化为 int 类型
Demo<double> d2;   // 实例化为 double 类型

template<typename T, typename C=less<T>> class PQ {};  // 带默认比较器模板
```
